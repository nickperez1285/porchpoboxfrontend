# Porch P.O. Box — Backlink Strategy to Build Page Authority

**Goal:** Build referring-domain diversity + domain authority so the site can rank for package-receiving / porch-piracy keywords in the SF Bay Area and nationally.

**Baseline (as of this writing):** ~16 indexable pages, zero known external backlinks, brand-new domain. GA4 (`G-VC8DQKBNCW`) is live for measurement.

---

## 1. Linkable Assets First (you must give sites a reason to link)

No one links to a landing page. Publish these assets, then pitch them:

| Asset | Format | Why it earns links |
|---|---|---|
| **"2026 Porch Piracy Report: Bay Area"** | Annual data study | Original data (burglary stats, package-theft incidents from PD open data, survey of residents). News + bloggers link to data. |
| **"Package Theft by Zip Code" map/table** | Interactive + embeddable widget | Every SF/Bay Area news site can embed it. Give them an iframe embed code. |
| **"How to Stop Porch Pirates" ultimate guide** | 3,000-word guide | Evergreen resource for HOA blogs, neighborhood sites, real-estate blogs. |
| **Porch-piracy news tracker / press page** | `/press` page with logos, quotes, stats, hi-res images | Journalists need facts + assets fast. Make it easy. |
| **Public safety alert email list** | Lead magnet | Builds an owned audience to amplify every future piece (backlinks follow). |
| **Free embeddable "delivery safety score" tool** | Widget | Tool links back to source by default. |

**SEO rule for all assets:** each links to `/#` (service) or `/plans` with descriptive anchor text ("secure package receiving service"). Publish 2 assets before starting outreach.

## 2. Digital PR (highest ROI) — the news hook is built-in

Porch piracy is a perennial local-news topic. Your product literally solves it.

**Targets (Bay Area):** SF Chronicle, SFist, The Mercury News, KTVU, KRON4, ABC7, NBC Bay Area, CBS Bay Area, SFGate, Patch.com (Burlingame/SF), Berkeleyside, Hoodline, The Bold Italic, 7x7, Eater SF (holiday package season), local NBC/ABC morning shows.

**Seasonal news peg:** Nov–Dec holiday delivery surge = pitch "how Bay Area residents can stop package theft this holiday season" every year.

**Tactics:**
- **HARO/Connectively + Featured** — respond daily to "porch theft," "package delivery," "home security," "shopping" queries. This is the cheapest path to authority links (Forbes, CNET, etc.). Sign up now.
- **Help a Reporter** and **Qwoted**, **ProfNet** as backups.
- **Expert commentary:** submit quotes on package-theft news within 24h of breaking stories (comment bylines earn links).
- **Data press releases** for the annual report via PR distribution (Muck Rack / Cision trial, or free: SendGrid + direct journalist emails).

**Outreach email template (cold, journalist):**

```
Subject: Bay Area porch-piracy data + a fix you can name-drop

Hi [First],

Porch piracy spikes again this holiday season. We analyzed [N] package-theft
incidents across Bay Area zips and found [X]. We also run a local network of
secure pickup spots [link] that eliminates the problem entirely.

Happy to share the full dataset, a map you can embed, or a quote for your piece.
[Data preview: one line]

Best,
[Name] | [phone] | [site]
```

## 4. Leverage the Partner Network (existing asset = instant links)

You already run a network of local partner locations. Convert it into links:

- **Partner page on your site** (`/become-a-partner`) already links *to* partners. Add a reciprocal-link agreement: each partner gets a "Recommended: get your packages here" page link *from* your site; in exchange they add a "Receive packages securely via Porch P.O. Box" link on *their* site (local businesses, cafes, coworking, corner stores).
- Give partners a **one-click embed badge** (HTML snippet) they paste on their site: "📦 Packages delivered securely through Porch P.O. Box."
- **Referral program** (`/referrals`) — add a backlink incentive tier to your referral rewards.
- Each partner link = a local, relevant, high-trust backlink. 20 partners = 20 unique local domains.

## 5. Niche Directories & Platforms (relevant authority)

Add the site to these industry-relevant lists (relevance beats DR when starting out):

- **Wikipedia:** only if genuinely notable — aim for a mention in a "package theft" or "P.O. box" article after you're covered by local news. Do NOT edit Wikipedia directly; use a disclosed contributor or wait for third-party coverage.

## 6. Content Marketing That Compounds

- **Skyscraper technique:** find the top-ranking "how to stop porch pirates" article; write a longer, better one with a comparison table (PO Box vs locker vs partner pickup vs doormat), original screenshots, and embeddable tools.
- **Guest posts** on Bay Area real-estate, home-security, and neighborhood blogs (2–4/mo, always with a bio link to porchpobox.com).
- **Community giveaway / sponsorship:** sponsor a local event (Chamber mixer, neighborhood watch) → event page + recap link.
- **Podcast appearances** on Bay Area real-estate/small-business podcasts → show-notes links.

---

## 7. Monitoring & Measurement (done via GA4 + free tools)

- **Google Search Console** — watch referring domains + which pages earn links.
- **GA4** — track `session_source` / referrers to see which links drive traffic.
- **Google Alerts** (brand name + "porchpobox.com") for new mentions.
- **Free backlink checkers monthly:** Google Search Console Links report; occasionally Ahrefs free checker / Bing Webmaster.
- **Goals:** Month 1: 10 unique domains. Month 3: 40. Month 6: 100+. Any spammy/PBN links → disavow via Search Console.

**Red flags to avoid:** paid links, link exchanges with unrelated sites, link farms, article-spun guest posts. All should be `nofollow`-safe or genuinely editorial.
